**Student Performance Analysis**

-> Project Overview

Student Performance Analysis is a Python-based data analysis project that focuses on analyzing students' academic performance using data analysis and visualization techniques.

The project uses Python libraries such as Pandas, NumPy, Matplotlib and Seaborn to clean, analyze and visualize student data.

It helps identify top-performing students, compare subject-wise performance, understand grade distribution and generate meaningful insights from the dataset.

-> Project Objectives

- Load and explore the student dataset.
- Identify and handle missing values.
- Remove duplicate records.
- Perform statistical analysis.
- Calculate subject-wise average marks.
- Identify top-performing students.
- Analyze student grade distribution.
- Compare subject-wise performance.
- Analyze pass and fail percentages.
- Generate meaningful insights using data visualization.

-> Project Workflow

1. Load Dataset

Imported the student dataset using Pandas.

2. Explore Dataset

Examined dataset structure, columns, data types and statistical information.

3. Data Cleaning

Handled missing values and removed duplicate records to improve data quality.

4. Statistical Analysis

Calculated mean, median, maximum, minimum and other statistical measurements.

5. Top-Performing Students

Identified students with the highest average marks and generated student rankings.

6. Data Visualization

Created charts and graphs using Matplotlib and Seaborn to understand student performance.

7. Generate Final Insights

Identified the best-performing subjects, weakest subjects, top students and pass percentages.
